# Contributing to Invoice Generator

Thank you for helping improve this project!

## Getting started

1. Fork and clone the repository.
2. Install dependencies: `npm install`
3. Copy env: `cp .env.example .env.local`
4. Run dev: `npm run dev`

## Before you open a PR

- Run `npm run typecheck`
- Run `npm run build`
- Keep changes focused — one feature or fix per PR
- Match existing code style and naming

## Reporting issues

Use [GitHub Issues](https://github.com/YuvisTechPoint/Invoice-Generator/issues) and include:

- Steps to reproduce
- Expected vs actual behavior
- Browser / OS / deployment target (local, Docker, Vercel)
